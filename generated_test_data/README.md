# Photo Frame Test Dataset

Generated by `generate_photo_frame_test_dataset.py`.

## What this dataset covers

- **gps_valid/**: happy-path JPEG images with valid EXIF GPS
- **gps_same_location/**: multiple JPEGs with the same GPS for cache / dedup tests
- **no_gps/**: JPEGs with no GPS metadata
- **invalid_gps/**: JPEGs containing intentionally invalid GPS coordinates
- **rotated/**: JPEGs with EXIF orientation flags for slideshow rendering tests
- **duplicates/**: byte-for-byte duplicate copies of valid JPEGs
- **corrupted/**: broken/truncated/random-byte files to test parser failure paths
- **heic/**: optional HEIC generation outputs or explanatory placeholders
- **videos_with_gps/**: optional MP4 videos with best-effort generic location metadata
- **videos_no_gps/**: optional MP4 videos with no location metadata
- **mixed_batch/**: representative mix for end-to-end pipeline tests

## Recommended uses

1. Run a **small mixed-batch** end-to-end flow first.
2. Run **full indexing** on the entire dataset.
3. Validate:
   - GPS parse success/failure separation
   - geocode cache reuse for same coordinates
   - no-GPS terminal behavior
   - retry/backoff handling for corrupted or invalid files
   - slideshow handling for rotated images and videos

## Command used

```bash
python generate_photo_frame_test_dataset.py --output ./test_data --clean
```

## Notes

- HEIC generation requires `pillow-heif`.
- Video generation requires `ffmpeg` on PATH.
- Video GPS metadata is only **best-effort** and may not be parseable by your current GPS extraction pipeline.
- For exact file inventory and metadata notes, see `manifest.json`.
