# Photo Frame Dashboard Frontend

## Run locally

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`
3. Open the local URL printed by Vite.

## Project structure

- `dashboard/` — frontend app shell, styles, views, and services
- `docs/` — current dashboard documents from the earlier bundle
- `generated_test_data/` — mock media assets used by the test pipeline UI

## Current scope

This bundle currently contains an unwired frontend only.
