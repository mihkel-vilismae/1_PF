# Terminal Demo Auth View Shells Proof

## Command

```bash
npm run proof:terminal-demo-auth-view-shells
```

## Proves

- View `D` renders an `iCloudPD authorization` section.
- The default authorization section has a read-only status row and `[I] Go to login view` shell.
- View `I` renders `NEW AUTH shell only` status.
- View `I` lists only the newer NEW AUTH button shells.
- Older compatibility auth buttons are absent.
- No auth execution is claimed or triggered by this shell.
- View `0` and View `6` are unchanged.

## Non-claims

This proof does not claim that iCloudPD login/auth functionality works. It proves shell visibility and scope safety only.
