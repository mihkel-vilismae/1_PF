# Terminal Demo View Shell Beeline Preflight Proof

## Command

```bash
npm run proof:terminal-demo-view-shell-beeline-preflight
```

## Proves

- The remaining-view beeline excludes new View `0` and View `6` feature work unless explicitly reopened.
- View `0` is currently the map/testing page with default route `0A` and custom route example `7D`.
- View `6` is currently the real fixture-backed playback page: queue-backed controls remain disabled, while fixture-backed controls generate browser-renderable HTML artifacts.
- View `D` and View `I` have implemented shell contracts, while View `L` and `1` through `5` remain documented planned shell contracts.
- View `I` documentation uses only the NEW AUTH button set and excludes older compatibility buttons.
- View `L` documentation lists the seven planned core log/status/truth file labels.
- Reusable component guidance names `SectionFrame`, `ViewMapSection`, `StatusRing`, `StatusRow`, `RpiStagesSection`, and `RpiWorkersSection`.

## Non-claims

This proof does not claim that View `L` or views `1` through `5` are implemented. It does not claim queue-backed playback, DB writes, cron, auth execution, worker execution, native fullscreen proof, or Raspberry hardware playback.
