# Terminal Demo View 0 Map + View 6 Merged Contract Proof

## Command

```bash
npm run proof:terminal-demo-view0-map-view6-blank
```

## Proves

- View `0` renders `map and testing - view 0`.
- View `0` contains a `VIEW MAP` section with `D`, `L`, `I`, and `1` through `6`.
- View `0` contains the `TESTING` section and default route entry point.
- Pressing each listed map key from View `0` routes to the expected page.
- View `6` renders the merged fixture-backed playback contract.
- View `6` still keeps queue-backed playback disabled.
- Uploaded docs `PF_login_View0_Map_Debug_Page_Overview_ACR.md` and `PF_login_View6_Playback_Page_Overview_XACR.md` are documented as scoped planning inputs.

## Non-Claims

Despite the historical package-script name, this proof no longer claims View 6 is blank. It does not prove real playback, queue execution, fullscreen playback, address-overlay playback, workers, auth, DB writes, cron, or hardware behavior.
