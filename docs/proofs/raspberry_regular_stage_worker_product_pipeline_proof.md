# Raspberry regular_stage_worker product pipeline proof

Command:

```bash
npm run proof:raspberry-regular-stage-worker-product-pipeline
```

This proof is the v1.0 evidence gate that `regular_stage_worker` performed product work instead of only runtime status/lock instrumentation.

## Required input

Provide:

```text
PF_RASPBERRY_REGULAR_STAGE_WORKER_PRODUCT_EVIDENCE_FILE=<path-to-redacted-product-evidence.json>
```

The evidence may be generated by:

```bash
npm run proof:regular-worker-product-evidence-producer
```

or supplied by an operator/device run that records the same schema.

## v2 evidence expectations

The proof expects a structured input → product → output chain:

```text
accepted manifest
→ selected eligible media
→ product record
→ display queue/output state
```

Core pass fields:

- accepted `source_kind`: `real_download_manifest` or `readiness_approved_manifest`;
- `input.items_seen > 0`;
- `input.items_eligible > 0`;
- selected media ID or file hash;
- product record created;
- media asset present;
- display queue written;
- next display item ready;
- private paths and secrets redacted.

## GPS/geocode separation

The proof tracks these fields:

- `gps_extraction_completed`;
- `geocode_completed`;
- `product_record.gps_status`;
- `product_record.geocode_status`.

However, real GPS/geocode provider truth belongs to the separate `real_gps_geocode` gate. This proof may pass the core worker product path while reporting GPS/geocode as `blocked`.

## Non-claims

- Does not itself download iCloud media.
- Does not itself prove real GPS/geocode provider output.
- Does not prove native playback.
- Does not prove address overlay visibility.
- Does not include credentials, cookies, raw provider output, private media paths, or raw media bytes.

## Status semantics

- `PASSED`: Raspberry target plus supplied structured regular-worker evidence proves accepted input → product → output.
- `BLOCKED`: target/evidence file is missing or this is not a Raspberry-like target.
- `FAILED`: evidence exists but is malformed, fake/incomplete, or leaks unsafe data.
