# Proof artifact schema

All proof JSON files generated by local proof runners use the same envelope shape.

```json
{
  "proof_kind": "example_kind",
  "baseline_version": "0.7.34",
  "git_commit": "short-commit",
  "proof_timestamp": "2026-05-31T00:00:00.000Z",
  "runtime_mode": "test | real | hardware",
  "proof_status": "PASSED | FAILED | BLOCKED | PARTIAL | TIMED_OUT",
  "evidence": {},
  "redaction_report": {
    "secrets_removed": true,
    "matched_patterns": [],
    "raw_provider_output_included": false
  },
  "known_limitations": []
}
```

A proof document may describe an intended workflow, but only generated runtime proof JSON from the relevant environment proves observed behavior.
