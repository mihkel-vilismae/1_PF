# Archive

Estonian timestamp: 2026-05-24 23:31 EEST

## Purpose

This folder is for historical documentation preserved for provenance.

## Belongs here

- old task docs.
- superseded indexes.
- historical prompts and implementation notes.
- docs kept only to understand prior decisions.

## Does not belong here

- latest current-truth docs.
- active runbooks.
- docs that future agents should treat as primary navigation.

## Authority rule

Archive docs preserve history. They should not be used as current truth unless current code/tests/evidence confirm them. Code, tests, generated evidence packs, and runtime artifacts are stronger than old documentation when there is a conflict.
